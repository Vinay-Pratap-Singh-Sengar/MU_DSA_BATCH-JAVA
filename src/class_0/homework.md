# Java First Program — Homework

## Instructions

* Create a separate `.java` file for each program.
* Use the `main()` method correctly.
* Use `System.out.println()` to display the output.
* Do not use variables yet.
* Try to solve the problems yourself before asking for help.
* Compile and run each program using `javac` and `java`.

# Submission Checklist

Before submitting your homework, check:

* [ ] Every program has a `.java` extension.
* [ ] Class name and file name match where required.
* [ ] `main()` method is written correctly.
* [ ] Every required statement has `;`.
* [ ] Braces `{ }` are properly closed.
* [ ] Programs compile without errors.
* [ ] Programs run successfully.
* [ ] Output is correct.
* [ ] Code is written by you.

# Important

For this homework, **do not use**:

```text
Scanner
variables
if-else
loops
arrays
functions/methods other than main()
```

We will use these concepts in upcoming classes.

### Goal

For now, your goal is simply:

```text
Write Code
    ↓
Save .java File
    ↓
Compile
    ↓
Run
    ↓
Check Output
```

**Complete the exercises on your own and practice typing the Java syntax. 💻**
