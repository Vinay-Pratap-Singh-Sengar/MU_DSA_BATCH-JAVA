# 🔵 LEVEL 4 — Digit Manipulation

## Important Concept

For digit manipulation, understand these two operations:

```text
n % 10
```

Used to get the **last digit**.

```text
n / 10
```

Used to **remove the last digit**.

Example:

```text
Number = 1234

1234 % 10 = 4
1234 / 10 = 123

123 % 10 = 3
123 / 10 = 12

12 % 10 = 2
12 / 10 = 1

1 % 10 = 1
1 / 10 = 0
```

# 📌 Rules for Homework

1. Write every program yourself.
2. Do not copy the solution from the internet.
3. First understand the logic, then write the code.
4. Use meaningful variable names.
5. Test your program with different inputs.
6. Try to handle `0` and negative numbers where applicable.
7. Write the **algorithm/logic** before writing the program.
8. Dry-run at least 2 programs in your notebook.
9. Do not use built-in functions for solving the main logic unless specifically allowed.
10. Ask yourself **"Why does this loop stop?"** before submitting the program.
